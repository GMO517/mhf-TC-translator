# 防具系列詞幹字典（全身共用）

> 五部位同一系列詞幹必須同譯。部位詞見各槽 `part-dict.md`（Arms護腕／Guard臂甲／Helm頭盔…）。
> 全表：`series-dict.tsv`。
> **組裝硬性（STYLE）：**整名最多一個`【】`、最多一個`・`（例：`S索倫護腕【ＳＰ】・黑`；禁`【Ｓ】【ＳＰ】`、禁`・赤・天`）。

## 查序（與 playbook A.3 同一套）

1. 整名語意  
2. `terms.csv` 魔物／縮寫／UI  
3. 神話／西洋典故  
4. 遊戲專名（Frontier 既定、**含合作／聯名**）  
5. **Web search**（台服 wiki／MH 大典／官方合作稿／可信中文慣譯）  
6. 字義／描述義譯  
7. 最後才短音譯或列待查  

**禁止**跳過 web search 直接音節灌表。合作裝只是專名的一類（例：`Miku`＝初音未來）。

**維護：** Agent **可逕行**增補（譯文／理由／出處）；不必停等使用者逐條批。  
**禁洗白：** `zh` 空白或理由僅「待查／音譯」→ **不得**拿去全表套用；須補 search／字義後才定稿。
