# 翻譯風格規範

適用於本專案所有 `target` 譯文與詞語庫。  
Agent 角色／停止條件見 `docs/agent-translation-playbook.md`（本檔只管用語與風格）。

## 語域

| 類型 | 要求 |
|------|------|
| 系統訊息／說明／教學 | 說明清楚、可操作，避免曖昧 |
| 短 UI（按鈕、標籤） | 簡潔；不必硬寫成完整句子 |
| NPC／日常對話 | 像人話；依角色調整正式／口語 |

## 用字與標點

- **數字**：半形（例：`12`、`HR100`）
- **標點**：全形（例：`，` `。` `！` `？` `「」` `：`）
- **漢字**：台灣慣用（繁體、用詞以台灣為準）
- **MH 詞彙（系列共通）**：以《魔物獵人荒野》官方／慣用繁中為準；玩家常講 ≥ 日文漢字
- **Frontier 專有（含邊境專屬魔物）**：以 [MHFO 台灣 wiki](https://w.atwiki.jp/mhfotw/) 為主找譯名；wiki 是玩家自編、可能缺漏或與日服現況不一致，**有衝突／缺條時對照日服原文與可信資料補齊**，仍無則標「找不到」（勿假設 wiki 已窮盡）
- **音譯感專有名詞**（例：Porta／ポルタ）：查詢順序固定為  
  1. 詞語庫已核准譯名  
  2. MHFO 台灣 wiki  
  3. 仍無 → web 搜尋玩家常用譯  
  4. 仍無 → 判斷是否遊戲自創名詞  
  5. 自創／無慣用 → **漢字音譯**（台灣慣用拼法；並可考慮入詞語庫）  
  有慣用譯時優先慣用，勿擅自另造。  
  **音譯＝繁中漢字音譯**（例：ポルタ→波爾塔、Mezeporta→梅傑波爾塔）。**禁止**用片假名當譯文。  
  **做完五步就要定案**：建議欄給出唯一寫法；註解只標 `音譯`／`義譯：…`／`wiki／既有`／`避半翻`。**禁止**註解寫「疑專名」「若…可改」把選擇丟回使用者。
- **禁止片假名混中文（硬規則）**：`target`／PENDING「建議」**不得**同時含片假名與漢字（例：禁 `トメンＩＭ票`、`ヴェラン頭票`、`ドラマ票`）。  
  - 系列字母碼（C／I／S…）可保留全形，後接**漢字**（義譯或漢字音譯）：`Ｉ大劍票`、`Ｃ・紋章票`、`托門ＩＭ票`。  
  - **禁止**「全形拉丁＋片假名」半翻（`Ｃクレスト票`）；也禁止「片假名＋字母／漢字」充數。  
  - 原文抽出已是日文形、尚未翻譯者不算譯文合格。  
- **拿不定專名**：比照詞語表流程——列入 `l10n/glossary/PENDING.md`（勿片假名充數）。  
  - 列入時**只填六欄**：**status → 原文 → 現況 → 建議 → 決定 → 註解**。建議必須是可定案的漢字寫法。  
  - 該 CATEGORY／子類**整段譯完後**，交使用者在「決定」欄給定譯；再由 Fixer 依定稿回修 CSV。  
  - 進行中可用保守**漢字**暫譯，並在 PENDING 標記。
- **定稿例**：`C Crest Tkt` → `Ｃ・紋章票`（Crest＝紋章）；`IM Tomen Tkt` → `托門ＩＭ票`（漢字音譯＋系列碼）。缺字用 `fallback_map`／白名單可顯示形（如「卡」→「可」）。
- **種別名**：剛種／烈種／始種／遷悠種／**辿異種**／極位等須入詞語庫；台服多直接用日文漢字（如「辿異種」）
- **辿異種魔物顯示形（定稿）**：統一 `辿異種‧XX`（例：`辿異種‧火龍`）。不用 `XX(辿異)`／無分隔的 `辿異種XX`。個別 UI 爆框再單條縮短。
- **詞語庫目的**：專有名詞與高頻常用詞入庫，避免同一概念前後譯法不一

## 不可更動

- 佔位符維持半形 ASCII，不翻譯、不改全形：`{j}` `{cNN}` `{/c}` `{K…}` `{i…}` `{u…}`
- 分組字串的 `{j}` **段數必須與原文相同**
- 無法通過字型／Shift-JIS 可顯示檢查的字，改用詞語庫 `fallback_glyph`，並在詞條註記

## 範圍

- 僅私服客戶端文字本地化
- 伺服端動態文案、圖片字（`*.txb`）、dll 內嵌字串預設另案／延後
